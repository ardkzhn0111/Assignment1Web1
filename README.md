# Coffee Culture — Educational Web Portal

A multi-page educational website dedicated to specialty coffee, espresso brewing history, beverage science, and tasting sessions. Developed as **Assignment 1: HTML & CSS Basics** for the Web Development course.

🔗 **Live Demo:** [https://ardkzhn0111.github.io/Assignment1Web1/](https://ardkzhn0111.github.io/Assignment1Web1/)

---

## 📁 Project Structure

* **`index.html` (Home):** Introduction to third-wave specialty coffee, single-origin flavor profiles (Ethiopia, Colombia, Kenya, Brazil), and a 5-step Hario V60 pour-over guide.
* **`about.html` (About Coffee Culture):** Espresso machine innovation timeline (1901–1961), extraction facts, comparative beverage specification table, and embedded video guide.
* **`contact.html` (Contact & Booking):** Interactive form for inquiries and cupping session reservations with diverse input controls.
* **`css/style.css`:** Centralized stylesheet built with pure Vanilla CSS, responsive layouts, and accessible UI states.
* **`images/`:** Optimized image assets with descriptive alt text and lazy loading.

---

## 🚀 Key Technical Features

### 1. Semantic HTML5 Architecture
* Structured entirely with semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<figure>`, `<figcaption>`, `<blockquote>`, `<cite>`, and `<footer>`.
* Single `<h1>` per page with strict heading hierarchy (`<h2>`) for SEO and accessibility.

### 2. Advanced Tables & Forms
* **W3C-compliant Table (`about.html`):** Includes `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, cell scope bindings (`scope="col"` / `scope="row"`), and `colspan`.
* **Accessible Form (`contact.html`):** Form controls organized via `<fieldset>` and `<legend>`, 1-to-1 `<label for="...">` associations, custom radio buttons, checkboxes, date picker, number constraints, and textarea.

### 3. Modern Vanilla CSS & Design System
* **CSS Reset & Box Model:** Universal `* { box-sizing: border-box; }` reset ensuring consistent element geometry.
* **Color System:** Harmonious palette utilizing **HEX** (`#2c1810`), **RGB** (`rgb(200, 122, 50)`), and **HSL** (`hsl(30, 43%, 97%)`).
* **Typography:** Clean sans-serif stack (`Arial, Helvetica, sans-serif`) paired with classic editorial serif (`Georgia, serif`) for headings and quotes.
* **Responsive Units:** Strategic blend of relative (`rem`, `%`, `em`, `vh`) and absolute (`px`) units for fluid adaptation across all screen sizes.
* **Interactive States:** Micro-animations for navigation links (`:hover`), zebra-striped tables with hover row highlights, and prominent illuminated focus rings (`:focus`) for keyboard accessibility.
